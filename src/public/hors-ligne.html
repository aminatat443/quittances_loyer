Serveur de l'application injoignable

Cette page est la coquille de l'application, conservée en cache par le navigateur. Les données ne sont pas enregistrées sur cet appareil : locataires, paiements et quittances vivent dans la base PostgreSQL du poste qui héberge l'application. Elles redeviendront accessibles dès que ce serveur sera allumé et joignable.

  • • Vérifiez que le service tourne : pm2 status ou npm start sur le poste hôte.
  • • Aucun document n'a été envoyé, imprimé ni modifié pendant cette coupure.
  • • Les brouillons WhatsApp et e-mail déjà ouverts dans le navigateur restent utilisables.
